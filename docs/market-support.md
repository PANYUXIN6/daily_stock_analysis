# A 股市场支持边界

本项目当前只提供中国 A 股分析。运行时市场标识固定为 `cn`，不再包含港股、美股、台股、日股或韩股的数据源、代码解析、市场日历与复盘策略。

## 支持对象

- 上海证券交易所上市 A 股、ETF 与其他可由现有 A 股数据源解析的六位证券代码。
- 深圳证券交易所上市 A 股、ETF 与其他可由现有 A 股数据源解析的六位证券代码。
- 北京证券交易所上市证券。
- `scripts/stock_index_seeds/index_registry.csv` 中已登记的 A 股指数。

普通六位代码按证券处理。指数必须使用已登记的明确身份，例如：

```text
600519
000858
300750
920493
sh000016
sz399006
930606.CSI
```

## 数据源

主行情链路按配置和可用性使用以下 A 股数据源：

- Efinance
- AkShare
- Tushare（可选 `TUSHARE_TOKEN`）
- Pytdx
- Baostock
- 腾讯与新浪直连能力
- TickFlow（可选 `TICKFLOW_API_KEY`）

单一数据源失败时，管理器会在兼容的数据源之间降级。不同数据集并非每个 provider 都支持；调用方应以数据能力接口返回的实际 `datasets` 与 `markets` 为准。

Futu OpenD 仅保留为可选的 A 股真实持仓导入入口，不参与行情 fallback。

## Portfolio 记账

账户及交易、资金流水、公司行动仅支持人民币（CNY）。历史外币记录保留供核对，但不参与估值与风险计算；不再提供汇率刷新和换算功能。

## 分析能力

- 日线与实时/近实时行情
- 技术指标、趋势与关键价位
- A 股基本面、资金、龙虎榜、板块与筹码能力（取决于数据源可用性）
- 新闻、公告与事件搜索
- A 股大盘复盘与 Market Light
- 决策信号、历史报告、回测、持仓与告警

## 明确不支持

- 非 A 股股票代码和海外指数。
- 海外市场专属交易日历、代码规范、数据源 fallback 与复盘策略。
- 将英文 ticker 或五位数字自动解释为海外证券。

不支持的输入应在解析或 API 校验边界被拒绝，而不是猜测市场或静默转成 A 股代码。

## 配置建议

最小配置只需要一个可用的大模型渠道与 A 股股票列表。需要稳定的长期任务时，再按需增加 Tushare、TickFlow、新闻搜索和通知渠道。完整变量说明见 [完整配置与部署指南](full-guide.md)。
