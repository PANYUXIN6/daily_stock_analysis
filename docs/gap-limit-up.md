# 跳空涨停选股（晚间复盘）

选择「跳空涨停」，或向现有 `POST /api/v1/screening/screen` 提交 `{"strategy":"gap_limit_up","market":"cn","max_results":5}`。此策略替代净利润断层，不再读取财报或要求公告次日；仅根据当日量价判断。

## 判定与行情口径

在全市场快照的基础过滤后、通用评分和候选截断之前，逐只核实：

1. 今天是交易日，且上海时区已到 22:00，使用当日完整日线。
2. 当日收盘价与 `hsstock/instrument/{code.EXCHANGE}` 的 `up` 按分相等。北交所使用 `bj/instrument`。必须同时核对证券身份及 `pc` 与当日日线前收盘价一致；不使用固定涨幅猜涨停。
3. 今日开盘价、最低价均高于前一交易日最高价。跨日比较用同一等比后复权 OHLC，收盘封板用不复权价；复权边界差距不超过 0.01 时不确认缺口。

当天即可入选，观察天数为 0。「缺口未回补」仅说明当天价格形态，不代表未来不会回补。当前策略不跟踪过去的缺口，也不使用涨停池和历史限价接口。

量能以此前 20 个交易日平均成交量为基准。一字涨停标记「尚未开板」；已开板且达到基准 2 倍标记「当日放量，后续待观察」；其他为「量能形态未确认」或「样本不足」。量能用于解释，不另设必须放量的硬门槛。一字板不保证次日可成交。

## 数据与配置

使用现有 `MAIRUI_LICENCE`。`instrument` 没有交易日期字段，因此运行日期、当日日线、前收盘价和证券身份都参与校验；数据未更新或缺失时明确排除/待核实。

同日快照的 OHLC 用于跳过明显不满足条件的股票；最终入选仍必须经过日线和当日涨停价核实。默认 180 秒总预算、单次请求最多 15 秒，达到预算保留已验证结果并提示覆盖不完整，不把未完成扫描当作全市场没有信号。

配置位于 `src/services/screening/strategies/gap_limit_up.yaml` 的 `screening.gap_limit_up`，仅保留量能基准、放量倍数与查询预算。原 `net_profit_gap` 策略 ID 和 `profit_gap` 配置已移除，自定义策略、调用方需迁移；财报增长、扣非比例、历史事件窗口等旧参数不再适用。

新证据写入 `raw.post_analysis_results.gap_limit_up`，摘要写入 `post_analysis_summaries.gap_limit_up`。旧净利润断层历史记录保留原证据并可继续展示，无数据库迁移。

验证覆盖封板/未封板、缺口触边、除权、复权舍入、过期数据、北交所路径、单证券故障隔离、超时保留结果及真实选股管线。停止使用可选择其他策略，或将 YAML 中的 `screening.enabled` 设为 `false` 并重启。
