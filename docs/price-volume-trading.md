# 量价波段分析范围

选股与单股分析统一以价格、成交量、趋势、流动性、支撑阻力、波动回撤和交易风险为依据。

## 选股

- 移除 PE/PB 硬过滤、`value` 估值因子、负 PE/高 PB 风险扣分、价值质量后置加分。剩余因子按原比例归一化，不将「PE 缺失」当作降级原因。
- 保留成交额、量比、换手、动量、反转、稳定性、规模及板块热度。规模用于交易流动性/风格，不用于判断内在价值。
- 麦蕊快照不再调用 `himk/syl`。旧 PE/PB 可选响应字段保留用于历史兼容，不参与筛选、评分或 AI 排序。
- 「趋势质量」描述趋势与量价质量；「净利润断层」改为[跳空涨停](gap-limit-up.md)，不再依赖财务数据或公告日期。
- 自定义策略需删除 PE/PB 过滤、`value` 权重及估值相关 scoring/risk/scorecard 参数。已移除的过滤与 profile 参数会被配置校验拒绝。

## 单股分析

统一数据入口不再查询估值、财报增长、扣非质量、分红、股息率和机构财务持仓包。保留资金流、龙虎榜、行业板块与量价行情；停牌、退市、监管、减持和其他已核实事件仍可作为交易风险提示。

传统分析、单 Agent、聊天和多 Agent 均使用量价波段分析要求；实时工具和分析提示不再提供 PE/PB，财报与分红表格不再生成。内置「成长质量」和「预期重估」单股技能移除，其他技能中的估值条件同步去掉。显式配置了这两个旧技能的调用方应改用现有量价技能，例如 `bull_trend`、`volume_breakout`、`shrink_pullback`。

现有 `ENABLE_FUNDAMENTAL_PIPELINE` 及其 timeout/cache 参数暂保留名称以兼容部署配置，其运行内容现仅是资金流、龙虎榜和板块。旧 `fundamental_context`/`fundamentals` 数据结构与历史报告字段保留；新分析不赋予基本面贡献，`fundamental_analysis` 为空。数据覆盖页面中的该聚合块显示为「资金与板块」。
