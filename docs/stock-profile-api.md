# A 股档案 API

`GET /api/v1/stocks/{stock_code}/profile` 返回 A 股标的的聚合档案。入口接受六位代码和常见上海、深圳、北京交易所前后缀；已登记指数按注册身份解析。

示例：

```http
GET /api/v1/stocks/600519/profile
GET /api/v1/stocks/SH600519/profile
GET /api/v1/stocks/600519.SH/profile
```

响应按可用性聚合以下区块：

- 行情与基础身份；
- 历史报告与研究产物；
- A 股基本面、资金、板块、公告和资讯；
- 数据来源、限制与降级信息。

可选数据块失败时接口返回 partial profile，不会因单一 provider 失败而丢弃其他可用区块。无法解析为 A 股证券或已登记 A 股指数的代码会返回明确的输入错误。

历史与资讯查询复用 A 股代码等价规则，例如 `600519`、`SH600519`、`600519.SH` 会收敛到同一证券身份；指数与同码普通证券仍按注册表身份隔离。
